# Arquitectura

Este directorio está reservado para documentación de arquitectura, diagramas y Architecture Decision Records (ADRs).

## Convención sugerida

Los ADRs futuros pueden usar el formato:

`ADR-NNN-titulo-corto.md`

Cada ADR debería incluir contexto, decisión, alternativas consideradas, consecuencias y estado. No se agregan decisiones aquí hasta que hayan sido revisadas y confirmadas.
