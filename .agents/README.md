# `.agents`

Esta carpeta contiene instrucciones y referencias de apoyo para el desarrollo asistido del proyecto.

## Estructura

- [`AGENTS.md`](./AGENTS.md): reglas globales de interacción y desarrollo.
- [`architecture/`](./architecture/): documentos de arquitectura y decisiones técnicas futuras.
- [`skills/`](./skills/): índice y documentación de skills de programación futuras.

## Mantenimiento

Los documentos deben mantenerse breves, verificables y alineados con la arquitectura real del proyecto. Las decisiones permanentes de arquitectura deben documentarse como ADRs dentro de `architecture/`, evitando duplicar reglas específicas ya definidas en archivos como `backend/AGENTS.md`.
